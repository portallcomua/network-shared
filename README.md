# Network Shared 2.0

Портативний застосунок для пошуку комп'ютерів у спільній локальній мережі та обміну файлами через Wi-Fi.

## Як користуватися

1. Запустіть `Network-Shared.exe` на обох комп'ютерах, підключених до одного Wi-Fi роутера.
2. На комп'ютері, який надає файли, виберіть папку та натисніть **«ВІДКРИТИ ДОСТУП ДО ПАПКИ»**.
3. На іншому комп'ютері дочекайтеся появи першого ПК у списку.
4. Виберіть його та натисніть **«ПІДКЛЮЧИТИСЯ»**.
5. У вікні файлів можна переходити між папками, передавати файли на віддалений комп'ютер і зберігати файли на свій ПК.

Програма не потребує інсталятора та не використовує Windows Shared Folders / SMB. На обох ПК запускається той самий EXE.

## Мережеві порти

- UDP 37020 — автоматичне виявлення комп'ютерів (broadcast).
- TCP 8080 — передавання файлів через WebDAV.

Якщо Windows Firewall покаже запит, дозвольте Network Shared доступ до приватних мереж. Обидва ПК мають бути в одній локальній мережі. Гостьова Wi-Fi мережа, ізоляція клієнтів (AP/client isolation), VPN або блокування broadcast роутером можуть перешкоджати автоматичному виявленню.

## Безпека

Спільна папка доступна без пароля всім пристроям, які можуть дістатися до порту 8080 цього комп'ютера. Використовуйте програму лише у довіреній приватній мережі та не відкривайте порт 8080 в Інтернет.

## Збірка EXE

GitHub Actions автоматично збирає Windows EXE після push. Готовий файл доступний у розділі Actions → останній успішний запуск → Artifacts → Network-Shared-Windows.

Локальна збірка:

```bash
python -m pip install -r requirements.txt
python -m py_compile network_shared.py
pyinstaller --noconfirm --clean --noconsole --onefile --collect-all wsgidav --collect-all cheroot --collect-all requests --icon=icon.ico --add-data "icon.ico;." --name Network-Shared network_shared.py
```
